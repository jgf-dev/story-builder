How To Use

A quick reminder for the local workflow.

Load your `TASKS.md`, make changes, and hit Save.
If you want the full productivity setup, run `/productivity:start`.
Keep tasks in the exact markdown sections the shared task board expects.
This dashboard does not depend on a server. It edits the file through the browser's file picker and download flow.
